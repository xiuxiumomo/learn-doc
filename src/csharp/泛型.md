## List使用



`List<T>` 是 `System.Collections.Generic` 下的泛型列表，**可变长度数组**，最常用集合。

> 需要引用：`using System.Collections.Generic;`



```csharp
// 空列表
List<int> list1 = new List<int>();

// 初始化赋值
List<string> list2 = new List<string> { "A", "B", "C" };

// 指定初始容量（优化，避免多次扩容）
List<double> list3 = new List<double>(10);

```

**增删数据**

```csharp
List<int> nums = new List<int> { 1, 2, 3 };

// 添加单个
nums.Add(4);

// 批量添加
nums.AddRange(new int[] {5,6});

// 插入到指定下标
nums.Insert(0, 99);

// 删除第一个匹配项
nums.Remove(2);

// 删除指定下标元素
nums.RemoveAt(0);

// 删除满足条件的所有项
nums.RemoveAll(x => x > 3);

// 清空
nums.Clear();

// 根据下标取值、修改
int v = nums[0];
nums[0] = 100;

// 是否包含元素
bool has = nums.Contains(3);

// 查找下标，找不到返回 -1
int idx = nums.IndexOf(3);

```



**遍历数据**



```csharp
// foreach
foreach(var item in nums)
{
    Console.WriteLine(item);
}

// for（需要下标时用）
for(int i = 0; i < nums.Count; i++)
{
    Console.WriteLine(nums[i]);
}

```



**Linq配合List**



```csharp
List<int> list = new List<int>{1,2,3,4,5};

var filter = list.Where(x => x > 2).ToList();
var sum = list.Sum();
var max = list.Max();
var first = list.FirstOrDefault(x=>x == 3);
var order = list.OrderBy(x=>x).ToList();

```



## 类的初始化



写接口的过程中初始化数据库有个奇怪的写法：



```csharp
using Microsoft.EntityFrameworkCore;
using MyFirstApi.Models;

namespace MyFirstApi.Data;


 public class BlogDbContext(DbContextOptions<BlogDbContext> options) : DbContext(options)
 {
 public DbSet<Post> Posts => Set<Post>();
   protected override void OnModelCreating(ModelBuilder modelBuilder)
   {
    modelBuilder.Entity<Post>(entity =>
     {
      entity.ToTable("Posts");
      entity.Property(p => p.Title).HasMaxLength(200).IsRequired();
      entity.Property(p => p.Author).HasMaxLength(50).IsRequired();
     entity.Property(p => p.Content).HasColumnType("longText").IsRequired();
    entity.Property(p => p.CreateAt).HasColumnType("datetime(6)");
     entity.Property(p => p.UpdateAt).HasColumnType("datetime(6)");
     entity.HasIndex(p => p.CreateAt);
  });
   }
 }
```

这里涉及到类的继承以及属性初始化。

以简单的例子来讲解，有一个`Ainmal` 类，它的构造函数接收名字：



```csharp
public class Animal{
    public string Name {get;}
    public Animal(string name){
           Name = name;
    }    

}

Animal animal = new Animal("小白");
Console.WriteLine(animal.Name) //输出 小白
```

子类继承它，也需要把名字交给父类。

现在定义一个`Dog` 类:



```csharp
public class Dog: Animal{
    public Dog(string name): base(name){
        
    }    

}
Dog dog = new Dog("旺财");
Console.WriteLine(dog.Name); // 输出：旺财
```

使用`c#12`  的主构造函数法可以简写：



```csharp
public class Dog(string name): Animal(name)
// 这样看起来就和上面的继承数据库是一样的拉。
```

在`js` 中也是类似实现的。



```js
//Animal.js

class Animal{
    constructor(name,age){
        this.name = name;
        this.age = age;
    }
}

class Dog extends Animal{
    constructor(name,age,breed){
        super(name,age);
        this.breed = breed; //自己的属性
    }
}

const dog = new Dog("旺财",3,"柴犬");

console.log(dog.name,dog.age,dog.breed)
```
