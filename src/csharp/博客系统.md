# 从零搭建 MyBlogApi（给 C# 初学者）

这份文档按当前博客接口项目的真实代码来写。你不需要先看懂全部原理。按顺序做，每一步都写了三件事：

1. **操作类型**：拉包、创建文件夹、创建文件、修改已有文件，还是只执行命令。
2. **放在哪里**：完整路径都相对于项目文件夹 `MyBlogApi/MyBlogApi`。
3. **具体代码**：下面的代码就是项目里正在用的代码，可以整段复制。

做完以后，你会得到这些能力：

- 用户注册、登录（登录后拿到 JWT）
- 查看和修改自己的资料、修改密码
- 文章分类
- 文章的新增、查询、修改、软删除
- 一级评论（不能回复别人的评论）
- Swagger 接口文档
- 已发布文章的列表和详情走 Redis 缓存

统一返回长这样。成功时 `code` 是 `200`：

```json
{
  "code": 200,
  "message": "成功",
  "result": {}
}
```

列表没有 `page`、`pageSize`。一次返回全部数据，并带上总条数：

```json
{
  "code": 200,
  "message": "成功",
  "result": {
    "total": 2,
    "data": []
  }
}
```

失败时 HTTP 状态码是 400、401、403、404 或 500，响应体里的 `code` 是 `1`，`message` 是原因。

## 0. 先认识几个词

| 词          | 在这个项目里是什么                                                                              |
| ----------- | ----------------------------------------------------------------------------------------------- |
| 实体 Entity | 和数据库表对应的 C# 类，放在 `Models/Entity`                                                    |
| DTO         | 接口收到或返回的数据形状，放在 `Models/Dto`。不要把数据库实体直接返回给前端，密码哈希不能露出去 |
| Controller  | 接口入口。它只接收请求、调用 Service、把结果返回                                                |
| Service     | 真正的业务：校验、查库、写库、缓存                                                              |
| DbContext   | EF Core 用来访问 SQL Server 的类，本项目叫 `AppDbContext`                                       |
| 拉包        | 用 `dotnet add package` 下载别人写好的库，不用自己写                                            |
| 迁移        | 根据 C# 实体生成建表 SQL，并在数据库里执行                                                      |
| JWT         | 登录成功后发的一串令牌。之后请求头带上它，服务器就知道你是谁                                    |

## 1. 准备环境

这一步不写代码。

你的电脑上需要：

- .NET SDK 11。命令行执行 `dotnet --version`，能看到 `11` 开头即可。
- Docker 里的 SQL Server，端口 `1433`，账号 `sa`。
- Docker 里的 Redis，端口 `6379`。

本项目的连接在 `appsettings.json` 里。数据库名是 `MyBlog`。Redis 连接串带密码和 0 号库。密码请换成你自己的，不要把真实密码提交到公开仓库。

## 2. 创建项目

**操作类型：执行命令。** 命令会创建文件夹和几个初始文件，不是你一个个新建的。

在你想放代码的目录打开 PowerShell：

```powershell
cd D:\netcore-project
dotnet new webapi -n MyBlogApi
cd MyBlogApi
```

模板会生成 `MyBlogApi.csproj`、`Program.cs`、`appsettings.json`、`Properties/launchSettings.json`。

如果模板还生成了 `WeatherForecast.cs` 或示例控制器，删掉它们。后面的 `Program.cs` 会整份替换。

`MyBlogApi.csproj` 里应能看到：

```xml
<TargetFramework>net11.0</TargetFramework>
<Nullable>enable</Nullable>
<ImplicitUsings>enable</ImplicitUsings>
```

`ImplicitUsings` 打开后，常见的 `using System;` 不用手写。`Nullable` 打开后，可能为空的字符串要写成 `string?`。

## 4. 安装 NuGet 包

**操作类型：拉包。** 在解决方案目录 `D:\netcore-project\MyBlogApi` 执行。每条命令都会改 `MyBlogApi.csproj`，并下载对应的库。

```powershell
cd D:\netcore-project\MyBlogApi
dotnet add MyBlogApi/MyBlogApi.csproj package Microsoft.EntityFrameworkCore.SqlServer --version 11.0.0
dotnet add MyBlogApi/MyBlogApi.csproj package Microsoft.EntityFrameworkCore.Design --version 11.0.0
dotnet add MyBlogApi/MyBlogApi.csproj package Microsoft.Extensions.Caching.StackExchangeRedis --version 11.0.0
dotnet add MyBlogApi/MyBlogApi.csproj package Swashbuckle.AspNetCore --version 11.0.1
dotnet add MyBlogApi/MyBlogApi.csproj package Microsoft.AspNetCore.Authentication.JwtBearer --version 11.0.0
```

每个包做什么：

| 包                                                | 作用                              |
| ------------------------------------------------- | --------------------------------- |
| `Microsoft.EntityFrameworkCore.SqlServer`         | 用 C# 操作 SQL Server             |
| `Microsoft.EntityFrameworkCore.Design`            | 让 `dotnet ef` 能根据实体生成迁移 |
| `Microsoft.Extensions.Caching.StackExchangeRedis` | 用 Redis 做缓存                   |
| `Swashbuckle.AspNetCore`                          | 生成 Swagger 页面                 |
| `Microsoft.AspNetCore.Authentication.JwtBearer`   | 校验登录后的 JWT                  |

如果模板自带 `Microsoft.AspNetCore.OpenApi`，可以删掉，本项目用 Swashbuckle：

```powershell
dotnet remove MyBlogApi/MyBlogApi.csproj package Microsoft.AspNetCore.OpenApi
```

再安装生成迁移的全局工具。**操作类型：执行命令，不是项目里的文件。**

```powershell
dotnet tool install --global dotnet-ef --version 11.0.0
```

已经装过会提示已安装，忽略即可。用 `dotnet ef --version` 确认能运行。

## 5. 修改配置文件

### 5.1 修改已有文件 `appsettings.json`

**操作类型：修改已有文件。**

连接串、JWT 都放这里。`Jwt:Secret` 至少 32 个字符，否则程序启动会抛异常。

```json
{
  "ConnectionStrings": {
    "SqlServer": "Server=localhost,1433;Database=MyBlog;User Id=sa;Password=你的数据库密码;TrustServerCertificate=True;MultipleActiveResultSets=true",
    "Redis": "127.0.0.1:6379,password=你的Redis密码,defaultDatabase=0"
  },
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "AllowedHosts": "*",
  "Jwt": {
    "Issuer": "MyBlogApi",
    "Audience": "MyBlogApi",
    "Secret": "MyBlogApi-dev-jwt-secret-key-2026-change-me",
    "ExpiresMinutes": 120
  }
}
```

`Server=localhost,1433` 里的逗号是端口，不是笔误。SQL Server 在 Docker 里映射到本机 1433 时就这样写。

`ExpiresMinutes` 是 token 有效分钟数，这里是 120 分钟。

`appsettings.Development.json` 保持模板即可，不必再写连接串。开发环境会先读 `appsettings.json`，再用 Development 文件覆盖同名项。

### 5.2 `Properties/launchSettings.json`

**操作类型：一般不用改。** 模板已经写好。本项目 http 地址是 `http://localhost:5184`。Swagger 地址是：

```text
http://localhost:5184/swagger
```

## 6. 创建实体

实体是数据库表在 C# 里的样子。先写类，后面用迁移命令建表。

关系先记住：

- 一个用户有多篇文章、多条评论。
- 一个分类有多篇文章。一篇文章只能属于一个分类。
- 一条评论只属于一篇文章、一个用户。没有“回复评论”，所以评论类里没有 `ParentId`。
- 删除用 `Restrict`：分类下面还有文章时，数据库不允许删分类；文章还在时，不允许删用户。

## 7. 创建 DTO

**操作类型：创建文件。** DTO 是接口的入参和出参。

带 `[Required]`、`[StringLength]` 的属性，如果前端没传或长度不对，框架会直接返回 400，不会进 Service。错误信息就是 `ErrorMessage` 里的中文。

### 7.1 `Models/Dto/RegisterRequest.cs`

```csharp
using System.ComponentModel.DataAnnotations;

namespace MyBlogApi.Models.Dto;

public class RegisterRequest
{
    [Required(ErrorMessage = "用户名不能为空")]
    [StringLength(50, MinimumLength = 3, ErrorMessage = "用户名长度为 3 到 50 个字符")]
    [RegularExpression(@"^\S+$", ErrorMessage = "用户名不能包含空格")]
    public string UserName { get; set; } = string.Empty;

    [Required(ErrorMessage = "邮箱不能为空")]
    [EmailAddress(ErrorMessage = "邮箱格式不正确")]
    [StringLength(256, ErrorMessage = "邮箱最长 256 个字符")]
    public string Email { get; set; } = string.Empty;

    [Required(ErrorMessage = "密码不能为空")]
    [StringLength(100, MinimumLength = 6, ErrorMessage = "密码长度为 6 到 100 个字符")]
    public string Password { get; set; } = string.Empty;

    [StringLength(50, ErrorMessage = "昵称最长 50 个字符")]
    public string? NickName { get; set; }
}
```

### 10.1 创建文件 `Common/Helpers/PasswordHasher.cs`

**操作类型：创建文件。** 不拉包。用 .NET 自带的 PBKDF2 把密码变成哈希。

`Hash` 在注册和改密码时调用。`Verify` 在登录和改密码时调用。数据库里看到的是类似 `PBKDF2$100000$盐$哈希` 的字符串。

```csharp
using System.Security.Cryptography;

namespace MyBlogApi.Common.Helpers;

public static class PasswordHasher
{
    private const int SaltSize = 16;
    private const int KeySize = 32;
    private const int Iterations = 100_000;
    private const string Prefix = "PBKDF2";

    public static string Hash(string password)
    {
        var salt = RandomNumberGenerator.GetBytes(SaltSize);
        var key = Rfc2898DeriveBytes.Pbkdf2(password, salt, Iterations, HashAlgorithmName.SHA256, KeySize);
        return $"{Prefix}${Iterations}${Convert.ToBase64String(salt)}${Convert.ToBase64String(key)}";
    }

    public static bool Verify(string password, string passwordHash)
    {
        try
        {
            var parts = passwordHash.Split('$');
            if (parts.Length != 4 || parts[0] != Prefix || !int.TryParse(parts[1], out var iterations))
            {
                return false;
            }

            var salt = Convert.FromBase64String(parts[2]);
            var expected = Convert.FromBase64String(parts[3]);
            var actual = Rfc2898DeriveBytes.Pbkdf2(password, salt, iterations, HashAlgorithmName.SHA256, expected.Length);
            return CryptographicOperations.FixedTimeEquals(actual, expected);
        }
        catch (FormatException)
        {
            return false;
        }
    }
}
```

### 10.3 创建文件 `Common/Helpers/RedisHelper.cs`

**操作类型：创建文件。** 对 Redis 缓存做一层封装。业务代码只调用 `GetAsync`、`SetAsync`、`RemoveAsync`，不用关心 Redis 的底层类型。

键会自动加上前缀 `MyBlog:`，这个前缀在后面的依赖注册里设置。

```csharp
using System.Text.Json;
using Microsoft.Extensions.Caching.Distributed;

namespace MyBlogApi.Common.Helpers;

public class RedisHelper(IDistributedCache cache)
{
    private static readonly JsonSerializerOptions JsonOptions = new(JsonSerializerDefaults.Web);

    public Task<string?> GetStringAsync(string key)
    {
        return cache.GetStringAsync(key);
    }

    public Task SetStringAsync(string key, string value, TimeSpan? expiry = null)
    {
        return cache.SetStringAsync(key, value, CreateOptions(expiry));
    }

    public Task RemoveAsync(string key)
    {
        return cache.RemoveAsync(key);
    }

    public async Task<T?> GetAsync<T>(string key)
    {
        var json = await cache.GetStringAsync(key);
        if (string.IsNullOrEmpty(json))
        {
            return default;
        }

        return JsonSerializer.Deserialize<T>(json, JsonOptions);
    }

    public Task SetAsync<T>(string key, T value, TimeSpan? expiry = null)
    {
        var json = JsonSerializer.Serialize(value, JsonOptions);
        return cache.SetStringAsync(key, json, CreateOptions(expiry));
    }

    private static DistributedCacheEntryOptions CreateOptions(TimeSpan? expiry)
    {
        var options = new DistributedCacheEntryOptions();
        if (expiry is not null)
        {
            options.AbsoluteExpirationRelativeToNow = expiry;
        }

        return options;
    }
}
```

### 10.6 创建文件 `Common/Extensions/ServiceCollectionExtensions.cs`

**操作类型：创建文件。** 这是把前面所有服务注册到依赖注入容器的地方。`Program.cs` 只调用 `AddBlogServices`，避免启动文件越来越长。

```csharp
using Microsoft.AspNetCore.Authentication.JwtBearer;
using Microsoft.AspNetCore.Mvc;
using Microsoft.EntityFrameworkCore;
using Microsoft.IdentityModel.Tokens;

namespace MyBlogApi.Common.Extensions;

public static class ServiceCollectionExtensions
{
    public static IServiceCollection AddBlogServices(this IServiceCollection services, IConfiguration configuration)
    {
        var jwtSection = configuration.GetSection(JwtOptions.SectionName);
        var jwt = jwtSection.Get<JwtOptions>() ?? throw new InvalidOperationException("缺少 Jwt 配置");
        if (string.IsNullOrWhiteSpace(jwt.Secret) || Encoding.UTF8.GetByteCount(jwt.Secret) < 32)

                    .Select(error => string.IsNullOrWhiteSpace(error.ErrorMessage) ? error.Exception?.Message : error.ErrorMessage)
                    .FirstOrDefault(text => !string.IsNullOrWhiteSpace(text))

        services.AddEndpointsApiExplorer();

                Type = SecuritySchemeType.Http,
                Scheme = "bearer",

            });

            options.AddSecurityRequirement(document => new OpenApiSecurityRequirement

                [new OpenApiSecuritySchemeReference("Bearer", document)] = []

        services.AddDbContext<AppDbContext>(options =>
```

### 11.1 认证 `IAuthService.cs` 和 `AuthService.cs`

注册会检查用户名、邮箱是否重复，密码只存哈希，成功后直接签发 token。登录可以用用户名或邮箱。密码错误统一说“用户名或密码错误”，不告诉别人这个账号存不存在。账号被禁用返回 403。

```csharp
using MyBlogApi.Models.Dto;
using MyBlogApi.Models.Result;

namespace MyBlogApi.Services.Interfaces;

public interface IAuthService
{
    Task<ServiceResult<AuthResponse>> RegisterAsync(RegisterRequest request);

    Task<ServiceResult<AuthResponse>> LoginAsync(LoginRequest request);
}
```

```csharp
using System.IdentityModel.Tokens.Jwt;
using System.Security.Claims;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Options;
using Microsoft.IdentityModel.Tokens;
using MyBlogApi.Common.Helpers;
using MyBlogApi.Data;
using MyBlogApi.Models.Dto;
using MyBlogApi.Models.Entity;
using MyBlogApi.Models.Result;
using MyBlogApi.Services.Interfaces;

namespace MyBlogApi.Services.Impl;

public class AuthService(AppDbContext db, IOptions<JwtOptions> jwtOptions) : IAuthService
{
    private readonly JwtOptions _jwt = jwtOptions.Value;

    public async Task<ServiceResult<AuthResponse>> RegisterAsync(RegisterRequest request)
    {
        var userName = request.UserName.Trim();
        var email = request.Email.Trim().ToLowerInvariant();
        var nickName = string.IsNullOrWhiteSpace(request.NickName) ? userName : request.NickName.Trim();

        if (await db.Users.AnyAsync(user => user.UserName == userName))
        {
            return ServiceResult<AuthResponse>.Fail(StatusCodes.Status400BadRequest, "用户名已存在");
        }

        if (await db.Users.AnyAsync(user => user.Email == email))
        {
            return ServiceResult<AuthResponse>.Fail(StatusCodes.Status400BadRequest, "邮箱已存在");
        }

        var now = DateTime.UtcNow;
        var user = new User
        {
            UserName = userName,
            Email = email,
            PasswordHash = PasswordHasher.Hash(request.Password),
            NickName = nickName,
            Role = UserRole.User,
            Status = UserStatus.Active,
            CreatedAt = now,
            UpdatedAt = now
        };

        db.Users.Add(user);

        try
        {
            await db.SaveChangesAsync();
        }
        catch (DbUpdateException)
        {
            return ServiceResult<AuthResponse>.Fail(StatusCodes.Status400BadRequest, "用户名或邮箱已存在");
        }

        return ServiceResult<AuthResponse>.Ok(CreateAuthResponse(user), "注册成功");
    }

    public async Task<ServiceResult<AuthResponse>> LoginAsync(LoginRequest request)
    {
        var account = request.Account.Trim();
        if (account.Contains('@'))
        {
            account = account.ToLowerInvariant();
        }

        var user = await db.Users.FirstOrDefaultAsync(
            item => item.UserName == account || item.Email == account);

        if (user is null || !PasswordHasher.Verify(request.Password, user.PasswordHash))
        {
            return ServiceResult<AuthResponse>.Fail(StatusCodes.Status401Unauthorized, "用户名或密码错误");
        }

        if (user.Status != UserStatus.Active)
        {
            return ServiceResult<AuthResponse>.Fail(StatusCodes.Status403Forbidden, "账号已被禁用");
        }

        return ServiceResult<AuthResponse>.Ok(CreateAuthResponse(user), "登录成功");
    }

    private AuthResponse CreateAuthResponse(User user)
    {
        var expiresAt = DateTime.UtcNow.AddMinutes(_jwt.ExpiresMinutes);
        var claims = new List<Claim>
        {
            new(ClaimTypes.NameIdentifier, user.Id.ToString()),
            new(ClaimTypes.Name, user.UserName),
            new(ClaimTypes.Email, user.Email),
            new(ClaimTypes.Role, user.Role.ToString())
        };

        var key = new SymmetricSecurityKey(System.Text.Encoding.UTF8.GetBytes(_jwt.Secret));
        var token = new JwtSecurityToken(
            issuer: _jwt.Issuer,
            audience: _jwt.Audience,
            claims: claims,
            expires: expiresAt,
            signingCredentials: new SigningCredentials(key, SecurityAlgorithms.HmacSha256));

        return new AuthResponse
        {
            Token = new JwtSecurityTokenHandler().WriteToken(token),
            ExpiresAt = expiresAt,
            UserId = user.Id,
            UserName = user.UserName,
            NickName = user.NickName,
            Email = user.Email,
            Role = user.Role.ToString()
        };
    }
}
```

```csharp
using Microsoft.EntityFrameworkCore;
using MyBlogApi.Common.Helpers;
```

```csharp
    public async Task<ServiceResult<List<CategoryDto>>> GetListAsync()
    {

    public async Task<ServiceResult<CategoryDto>> GetAsync(long id)

    public async Task<ServiceResult<CategoryDto>> CreateAsync(CategoryAddDto request)
    {
        var name = request.Name.Trim();
        if (name.Length == 0)
        {
            return ServiceResult<CategoryDto>.Fail(StatusCodes.Status400BadRequest, "分类名称不能为空");
        }

        if (await db.Categories.AnyAsync(category => category.Name == name))
        {
            return ServiceResult<CategoryDto>.Fail(StatusCodes.Status400BadRequest, "分类名称已存在");
        }

        var now = DateTime.UtcNow;
        var category = new Category
        {
            Name = name,
            Description = NormalizeOptional(request.Description),
            Sort = request.Sort,
            CreatedAt = now,
            UpdatedAt = now
        };

        db.Categories.Add(category);
        try
        {
            await db.SaveChangesAsync();
        }
        catch (DbUpdateException)
        {
            return ServiceResult<CategoryDto>.Fail(StatusCodes.Status400BadRequest, "分类名称已存在");
        }

        return ServiceResult<CategoryDto>.Ok(ToDto(category), "分类已创建");
    }

    public async Task<ServiceResult<CategoryDto>> UpdateAsync(long id, CategoryUpdateDto request)
    {
        var name = request.Name.Trim();
        if (name.Length == 0)
        {
            return ServiceResult<CategoryDto>.Fail(StatusCodes.Status400BadRequest, "分类名称不能为空");
        }

        var category = await db.Categories.FirstOrDefaultAsync(item => item.Id == id);
        if (category is null)
        {
            return ServiceResult<CategoryDto>.Fail(StatusCodes.Status404NotFound, "分类不存在");
        }

        if (await db.Categories.AnyAsync(item => item.Id != id && item.Name == name))
        {
            return ServiceResult<CategoryDto>.Fail(StatusCodes.Status400BadRequest, "分类名称已存在");
        }

        category.Description = NormalizeOptional(request.Description);
        category.Sort = request.Sort;
        category.UpdatedAt = DateTime.UtcNow;

        try
        {
            await db.SaveChangesAsync();
        }
        catch (DbUpdateException)

            return ServiceResult<CategoryDto>.Fail(StatusCodes.Status400BadRequest, "分类名称已存在");

        return ServiceResult<CategoryDto>.Ok(ToDto(category), "分类已更新");

    {

        if (category is null)
        {
            return ServiceResult<object?>.Fail(StatusCodes.Status404NotFound, "分类不存在");
        }

        var hasArticles = await db.Articles.AnyAsync(article => article.CategoryId == id);

        {
            await db.SaveChangesAsync();
        }
        catch (DbUpdateException)

    private async Task InvalidateArticleCacheAsync(long categoryId)
    {
        try
        {

                .Where(article => article.CategoryId == categoryId)
                .Select(article => article.Id)
                .ToListAsync();

            await redis.SetStringAsync(ArticleCacheKeys.ListVersion, Guid.NewGuid().ToString("N"), null);
            foreach (var articleId in articleIds)
            {
                await redis.RemoveAsync(ArticleCacheKeys.Detail(articleId));
            }
        }
        catch (Exception exception) when (exception is not OperationCanceledException)
        {
            logger.LogWarning(exception, "更新分类后清理文章缓存失败");
        }
    }

    private static string? NormalizeOptional(string? value)
    {
        return string.IsNullOrWhiteSpace(value) ? null : value.Trim();
    }

    private static CategoryDto ToDto(Category category)
    {
        return new CategoryDto
        {
            Id = category.Id,
            Name = category.Name,
            Description = category.Description,
            Sort = category.Sort,
            CreatedAt = category.CreatedAt
        };
    }
```

### 11.4 文章 `IArticleService.cs` 和 `ArticleService.cs`

规则：

- 公开列表只含已发布、未删除的文章。可以按 `categoryId` 筛选。
- `mine` 是当前用户自己的文章，含草稿，不走 Redis。
- 草稿详情只有作者能看。别人看草稿，返回 404，避免别人知道这篇草稿存在。
- 别人打开已发布文章，阅读数加 1。作者自己看，不加。
- 已发布列表缓存 5 分钟，详情缓存 10 分钟。发布、修改、删除会更换列表版本并删掉该文详情缓存。
- Redis 出错时记一条警告，改回直接查数据库，接口仍然可用。
- 只能改、删自己的文章。

```csharp
namespace MyBlogApi.Services.Interfaces;

public interface IArticleService

    Task<ServiceResult<ArticleDetailDto>> CreateAsync(long userId, ArticleAddDto request);

    Task<ServiceResult<ArticleDetailDto>> UpdateAsync(long id, long userId, ArticleUpdateDto request);
```

```csharp
using Microsoft.EntityFrameworkCore;
using MyBlogApi.Common.Helpers;
using MyBlogApi.Data;
using MyBlogApi.Models.Dto;
using MyBlogApi.Models.Entity;
using MyBlogApi.Models.Result;
using MyBlogApi.Services.Interfaces;

namespace MyBlogApi.Services.Impl;

public class ArticleService(AppDbContext db, RedisHelper redis, ILogger<ArticleService> logger) : IArticleService
{
    private static readonly TimeSpan ListCacheTtl = TimeSpan.FromMinutes(5);
    private static readonly TimeSpan DetailCacheTtl = TimeSpan.FromMinutes(10);

    public async Task<ServiceResult<PagedResult<ArticleDto>>> GetPublishedAsync(
        long? categoryId)
    {
        if (categoryId is not null && !await db.Categories.AnyAsync(category => category.Id == categoryId))
        {
            return ServiceResult<PagedResult<ArticleDto>>.Fail(StatusCodes.Status404NotFound, "分类不存在");
        }

        var version = await ReadStringAsync(ArticleCacheKeys.ListVersion) ?? "0";
        var cacheKey = ArticleCacheKeys.PublishedList(version, categoryId);
        var cached = await ReadCacheAsync<PagedResult<ArticleDto>>(cacheKey);
        if (cached is not null)
        {
            return ServiceResult<PagedResult<ArticleDto>>.Ok(cached, "成功");
        }

        var query = db.Articles.AsNoTracking()
            .Where(article => !article.IsDeleted && article.Status == ArticleStatus.Published);
        if (categoryId is not null)
        {
            query = query.Where(article => article.CategoryId == categoryId);
        }
        var result = await ListAsync(query, article => article.PublishedAt);
        if (result.Succeeded && result.Data is not null)
        {
            await WriteCacheAsync(cacheKey, result.Data, ListCacheTtl);
        }

        return result;
    }

    public async Task<ServiceResult<PagedResult<ArticleDto>>> GetMineAsync(long userId)
    {
        var author = await FindActiveAuthorAsync(userId);
        if (author.Error is not null)
        {
            return ServiceResult<PagedResult<ArticleDto>>.Fail(author.Error.Value.StatusCode, author.Error.Value.Message);
        }

        var query = db.Articles.AsNoTracking()
            .Where(article => !article.IsDeleted && article.UserId == userId);
        return await ListAsync(query, article => article.UpdatedAt);
    }

    public async Task<ServiceResult<ArticleDetailDto>> GetAsync(long id, long? currentUserId)
    {
        var cacheKey = ArticleCacheKeys.Detail(id);
        var cached = await ReadCacheAsync<ArticleDetailDto>(cacheKey);
        if (cached is not null && cached.Status == nameof(ArticleStatus.Published) && cached.UserId != currentUserId)
        {
            await IncrementViewCountAsync(id);
            cached.ViewCount += 1;
            await WriteCacheAsync(cacheKey, cached, DetailCacheTtl);
            return ServiceResult<ArticleDetailDto>.Ok(cached, "成功");
        }

        var article = await db.Articles.AsNoTracking()
            .Include(item => item.User)
            .Include(item => item.Category)
            .FirstOrDefaultAsync(item => item.Id == id && !item.IsDeleted);

        if (article is null || (article.Status != ArticleStatus.Published && article.UserId != currentUserId))
        {
            return ServiceResult<ArticleDetailDto>.Fail(StatusCodes.Status404NotFound, "文章不存在");
        }

        var detail = ToDetail(article);
        if (article.Status == ArticleStatus.Published && article.UserId != currentUserId)
        {
            await IncrementViewCountAsync(id);
            detail.ViewCount += 1;
        }

        if (article.Status == ArticleStatus.Published)
        {
            await WriteCacheAsync(cacheKey, detail, DetailCacheTtl);
        }

        return ServiceResult<ArticleDetailDto>.Ok(detail, "成功");
    }

    public async Task<ServiceResult<ArticleDetailDto>> CreateAsync(long userId, ArticleAddDto request)
    {
        var author = await FindActiveAuthorAsync(userId);
        if (author.Error is not null || author.User is null)
        {
            return ServiceResult<ArticleDetailDto>.Fail(author.Error!.Value.StatusCode, author.Error.Value.Message);
        }

        var fields = Normalize(request.Title, request.Summary, request.Content, request.CoverImage, request.Status);
        if (fields.Error is not null)
        {
            return ServiceResult<ArticleDetailDto>.Fail(StatusCodes.Status400BadRequest, fields.Error);
        }

        var category = await FindCategoryAsync(request.CategoryId);
        if (category is null)
        {
            return ServiceResult<ArticleDetailDto>.Fail(StatusCodes.Status400BadRequest, "分类不存在");
        }

        var now = DateTime.UtcNow;
        var article = new Article
        {
            UserId = userId,
            CategoryId = category.Id,
            Title = fields.Title,
            Summary = fields.Summary,
            Content = fields.Content,
            CoverImage = fields.CoverImage,
            Status = fields.Status,
            PublishedAt = fields.Status == ArticleStatus.Published ? now : null,
            CreatedAt = now,
            UpdatedAt = now,
            User = author.User,
            Category = category
        };

        db.Articles.Add(article);
        await db.SaveChangesAsync();
        if (article.Status == ArticleStatus.Published)
        {
            await InvalidatePublishedCacheAsync(null);
        }

        return ServiceResult<ArticleDetailDto>.Ok(ToDetail(article), "文章已创建");
    }

    public async Task<ServiceResult<ArticleDetailDto>> UpdateAsync(
        long id,
        long userId,
        ArticleUpdateDto request)
    {
        var author = await FindActiveAuthorAsync(userId);
        if (author.Error is not null)
        {
            return ServiceResult<ArticleDetailDto>.Fail(author.Error.Value.StatusCode, author.Error.Value.Message);
        }

        var article = await db.Articles.Include(item => item.User)
            .Include(item => item.Category)
            .FirstOrDefaultAsync(item => item.Id == id && !item.IsDeleted);
        if (article is null)
        {
            return ServiceResult<ArticleDetailDto>.Fail(StatusCodes.Status404NotFound, "文章不存在");
        }

        if (article.UserId != userId)
        {
            return ServiceResult<ArticleDetailDto>.Fail(StatusCodes.Status403Forbidden, "无权修改这篇文章");
        }

        var fields = Normalize(request.Title, request.Summary, request.Content, request.CoverImage, request.Status);
        if (fields.Error is not null)
        {
            return ServiceResult<ArticleDetailDto>.Fail(StatusCodes.Status400BadRequest, fields.Error);
        }

        var category = await FindCategoryAsync(request.CategoryId);
        if (category is null)
        {
            return ServiceResult<ArticleDetailDto>.Fail(StatusCodes.Status400BadRequest, "分类不存在");
        }

        var now = DateTime.UtcNow;
        article.CategoryId = category.Id;
        article.Category = category;
        article.Title = fields.Title;
        article.Summary = fields.Summary;
        article.Content = fields.Content;
        article.CoverImage = fields.CoverImage;
        article.Status = fields.Status;
        if (fields.Status == ArticleStatus.Published && article.PublishedAt is null)
        {
            article.PublishedAt = now;
        }

        article.UpdatedAt = now;
        await db.SaveChangesAsync();
        await InvalidatePublishedCacheAsync(article.Id);
        return ServiceResult<ArticleDetailDto>.Ok(ToDetail(article), "文章已更新");
    }

    public async Task<ServiceResult<object?>> DeleteAsync(long id, long userId)
    {
        var author = await FindActiveAuthorAsync(userId);
        if (author.Error is not null)
        {
            return ServiceResult<object?>.Fail(author.Error.Value.StatusCode, author.Error.Value.Message);
        }

        var article = await db.Articles.FirstOrDefaultAsync(item => item.Id == id && !item.IsDeleted);
        if (article is null)
        {
            return ServiceResult<object?>.Fail(StatusCodes.Status404NotFound, "文章不存在");
        }

        if (article.UserId != userId)
        {
            return ServiceResult<object?>.Fail(StatusCodes.Status403Forbidden, "无权删除这篇文章");
        }

        article.IsDeleted = true;
        article.UpdatedAt = DateTime.UtcNow;
        await db.SaveChangesAsync();
        await InvalidatePublishedCacheAsync(article.Id);
        return ServiceResult<object?>.Ok(null, "文章已删除");
    }

    private async Task IncrementViewCountAsync(long id)
    {
        await db.Articles
            .Where(item => item.Id == id && !item.IsDeleted)
            .ExecuteUpdateAsync(setters => setters.SetProperty(item => item.ViewCount, item => item.ViewCount + 1));
    }

    private async Task InvalidatePublishedCacheAsync(long? articleId)
    {
        await WriteStringAsync(ArticleCacheKeys.ListVersion, Guid.NewGuid().ToString("N"), null);
        if (articleId is not null)
        {
            await RemoveCacheAsync(ArticleCacheKeys.Detail(articleId.Value));
        }
    }

    private async Task<string?> ReadStringAsync(string key)
    {
        try
        {
            return await redis.GetStringAsync(key);
        }
        catch (Exception exception) when (exception is not OperationCanceledException)
        {
            logger.LogWarning(exception, "读取 Redis 失败，键 {CacheKey}", key);
            return null;
        }
    }

    private async Task<T?> ReadCacheAsync<T>(string key)
    {
        try
        {
            return await redis.GetAsync<T>(key);
        }
        catch (Exception exception) when (exception is not OperationCanceledException)
        {
            logger.LogWarning(exception, "读取 Redis 失败，键 {CacheKey}", key);
            return default;
        }
    }

    private async Task WriteCacheAsync<T>(string key, T value, TimeSpan ttl)
    {
        try
        {
            await redis.SetAsync(key, value, ttl);
        }
        catch (Exception exception) when (exception is not OperationCanceledException)
        {
            logger.LogWarning(exception, "写入 Redis 失败，键 {CacheKey}", key);
        }
    }

    private async Task WriteStringAsync(string key, string value, TimeSpan? ttl)
    {
        try
        {
            await redis.SetStringAsync(key, value, ttl);
        }
        catch (Exception exception) when (exception is not OperationCanceledException)
        {
            logger.LogWarning(exception, "写入 Redis 失败，键 {CacheKey}", key);
        }
    }

    private async Task RemoveCacheAsync(string key)
    {
        try
        {
            await redis.RemoveAsync(key);
        }
        catch (Exception exception) when (exception is not OperationCanceledException)
        {
            logger.LogWarning(exception, "删除 Redis 失败，键 {CacheKey}", key);
        }
    }

    private async Task<ServiceResult<PagedResult<ArticleDto>>> ListAsync(
        IQueryable<Article> query,
        System.Linq.Expressions.Expression<Func<Article, DateTime?>> orderBy)
    {
        var items = await query
            .OrderByDescending(orderBy)
            .ThenByDescending(article => article.Id)
            .Select(article => new ArticleDto
            {
                Id = article.Id,
                Title = article.Title,
                Summary = article.Summary,
                CoverImage = article.CoverImage,
                Status = article.Status == ArticleStatus.Published ? "Published" : "Draft",
                ViewCount = article.ViewCount,
                PublishedAt = article.PublishedAt,
                CreatedAt = article.CreatedAt,
                UserId = article.UserId,
                AuthorName = article.User.NickName,
                CategoryId = article.CategoryId,
                CategoryName = article.Category.Name
            })
            .ToListAsync();

        return ServiceResult<PagedResult<ArticleDto>>.Ok(new PagedResult<ArticleDto>
        {
            Total = items.Count,
            Data = items

    private static (string Title, string? Summary, string Content, string? CoverImage, ArticleStatus Status, string? Error) Normalize(
        string title,
        string? summary,
        string content,
        string? coverImage,
        ArticleStatus status)
    {
        title = title.Trim();
        content = content.Trim();
        if (title.Length == 0)
        {
            return (title, null, content, null, status, "标题不能为空");
        }

        if (content.Length == 0)
        {
            return (title, null, content, null, status, "正文不能为空");
        }

        if (status is not ArticleStatus.Draft and not ArticleStatus.Published)
        {
            return (title, null, content, null, status, "文章状态不正确");
```

```csharp
using MyBlogApi.Models.Dto;
using MyBlogApi.Models.Result;

namespace MyBlogApi.Services.Interfaces;

public interface ICommentService
{
    Task<ServiceResult<PagedResult<CommentDto>>> GetListAsync(long articleId);
```

```csharp
using Microsoft.EntityFrameworkCore;
using MyBlogApi.Data;
using MyBlogApi.Models.Dto;
using MyBlogApi.Models.Entity;
using MyBlogApi.Models.Result;
using MyBlogApi.Services.Interfaces;

namespace MyBlogApi.Services.Impl;

public class CommentService(AppDbContext db) : ICommentService
{
    public async Task<ServiceResult<PagedResult<CommentDto>>> GetListAsync(long articleId)
    {
        if (!await PublishedArticleExistsAsync(articleId))
        {
            return ServiceResult<PagedResult<CommentDto>>.Fail(StatusCodes.Status404NotFound, "文章不存在");
        }

        var items = await db.Comments.AsNoTracking()
            .Where(comment => comment.ArticleId == articleId && !comment.IsDeleted)
            .OrderByDescending(comment => comment.CreatedAt)
            .ThenByDescending(comment => comment.Id)
            .Select(comment => new CommentDto
            {
                Id = comment.Id,
                ArticleId = comment.ArticleId,
                UserId = comment.UserId,
                AuthorName = comment.User.NickName,
                Avatar = comment.User.Avatar,
                Content = comment.Content,
                CreatedAt = comment.CreatedAt
            })
            .ToListAsync();

        return ServiceResult<PagedResult<CommentDto>>.Ok(new PagedResult<CommentDto>
        {
            Total = items.Count,
            Data = items
        }, "成功");
    }

    public async Task<ServiceResult<CommentDto>> CreateAsync(
        long articleId,
        long userId,
        CommentAddDto request)
    {
        var user = await FindActiveUserAsync(userId);
        if (user.Error is not null || user.User is null)
        {
            return ServiceResult<CommentDto>.Fail(user.Error!.Value.StatusCode, user.Error.Value.Message);
        }

        if (!await PublishedArticleExistsAsync(articleId))
        {
            return ServiceResult<CommentDto>.Fail(StatusCodes.Status404NotFound, "文章不存在");
        }

        var content = request.Content.Trim();
        if (content.Length == 0)
        {
            return ServiceResult<CommentDto>.Fail(StatusCodes.Status400BadRequest, "评论内容不能为空");
        }

        var now = DateTime.UtcNow;
        var comment = new Comment
        {
            ArticleId = articleId,
            UserId = userId,
            Content = content,
            CreatedAt = now,
            UpdatedAt = now,
            User = user.User
        };

        db.Comments.Add(comment);
        await db.SaveChangesAsync();
        return ServiceResult<CommentDto>.Ok(ToDto(comment), "评论已发布");
    }

    public async Task<ServiceResult<object?>> DeleteAsync(long id, long userId)
    {
        var user = await FindActiveUserAsync(userId);
        if (user.Error is not null)
        {
            return ServiceResult<object?>.Fail(user.Error.Value.StatusCode, user.Error.Value.Message);
        }

        var comment = await db.Comments
            .Include(item => item.Article)
            .FirstOrDefaultAsync(item => item.Id == id && !item.IsDeleted);
        if (comment is null)
        {
            return ServiceResult<object?>.Fail(StatusCodes.Status404NotFound, "评论不存在");
        }

        if (comment.UserId != userId && comment.Article.UserId != userId)
        {
            return ServiceResult<object?>.Fail(StatusCodes.Status403Forbidden, "无权删除这条评论");
        }

        comment.IsDeleted = true;
        comment.UpdatedAt = DateTime.UtcNow;
        await db.SaveChangesAsync();
        return ServiceResult<object?>.Ok(null, "评论已删除");
    }

    private Task<bool> PublishedArticleExistsAsync(long articleId)
    {
        return db.Articles.AnyAsync(
            article => article.Id == articleId && !article.IsDeleted && article.Status == ArticleStatus.Published);
    }

    private async Task<(User? User, (int StatusCode, string Message)? Error)> FindActiveUserAsync(
        long userId)
    {
        var user = await db.Users.FirstOrDefaultAsync(item => item.Id == userId);
        if (user is null)
        {
            return (null, (StatusCodes.Status401Unauthorized, "未登录或登录已失效"));
        }

        if (user.Status != UserStatus.Active)
        {
            return (null, (StatusCodes.Status403Forbidden, "账号已被禁用"));
        }

        return (user, null);
    }

    private static CommentDto ToDto(Comment comment)
    {
        return new CommentDto
        {
            Id = comment.Id,
            ArticleId = comment.ArticleId,
            UserId = comment.UserId,
            AuthorName = comment.User.NickName,
            Avatar = comment.User.Avatar,
            Content = comment.Content,
            CreatedAt = comment.CreatedAt
        };
    }
}
```

## 12. 创建控制器

**操作类型：创建文件。**

控制器不写业务。它做三件事：读路由和 body、从 token 里取出用户 Id、调用 Service 并把 `ServiceResult` 转成 HTTP 响应。

`[Authorize]` 表示必须登录。没有这个特性的接口，不登录也能访问。

### 12.1 `Controllers/BaseController.cs`

所有控制器继承它。

- `TryGetUserId`：从 JWT 的 `NameIdentifier` 取出用户 Id。登录时我们把用户 Id 放进了这个声明。
- `ToActionResult`：成功返回 HTTP 200，并且 `code` 为 200。失败按 Service 里的状态码返回。

```csharp
using System.Security.Claims;
using Microsoft.AspNetCore.Mvc;
using MyBlogApi.Models.Result;

namespace MyBlogApi.Controllers;

[ApiController]
public abstract class BaseController : ControllerBase
{
    protected bool TryGetUserId(out long userId)
    {
        var value = User.FindFirstValue(ClaimTypes.NameIdentifier);
        return long.TryParse(value, out userId);
    }

    protected ActionResult<ApiResult<T>> ToActionResult<T>(ServiceResult<T> result)
    {
        if (!result.Succeeded)
        {
            return StatusCode(result.StatusCode, ApiResult<T>.Fail(result.Message));
        }

        return Ok(ApiResult<T>.Ok(result.Data!, result.Message));
    }
}
```

## 14. 用命令建表

**操作类型：执行命令。** 不要手写 `Data/Migrations` 里的文件。

这三条命令要分开看：

1. `migrations add`：对比当前实体和上一次迁移，生成 C# 迁移文件。第一次会创建 `Users`、`Articles`。后面两次分别加上 `Categories`、`Comments`。你要从零做，可以只执行一次 `InitialCreate`，前提是实体已经全部写完。下面按“实体一次写完”来做，所以只需要一次迁移。
2. `database update`：连上 `appsettings.json` 里的 SQL Server，真正建库建表。
3. `has-pending-model-changes`：检查实体和迁移是否一致。输出 `No changes` 就对了。

在解决方案目录执行：

```powershell
cd D:\netcore-project\MyBlogApi
dotnet ef migrations add InitialCreate --project MyBlogApi/MyBlogApi.csproj --output-dir Data/Migrations
dotnet ef database update --project MyBlogApi/MyBlogApi.csproj
dotnet ef migrations has-pending-model-changes --project MyBlogApi/MyBlogApi.csproj
```

成功后数据库 `MyBlog` 里会有这些表：

| 表                      | 作用                                           |
| ----------------------- | ---------------------------------------------- |
| `Users`                 | 用户                                           |
| `Categories`            | 分类                                           |
| `Articles`              | 文章。`UserId` 指向用户，`CategoryId` 指向分类 |
| `Comments`              | 评论。`ArticleId` 指向文章，`UserId` 指向用户  |
| `__EFMigrationsHistory` | EF 自己用来记录已经执行过哪些迁移              |

如果 `database update` 报连接失败，先确认 Docker 里的 SQL Server 已启动，并且密码和 `appsettings.json` 一致。

以后只改了实体，再执行一次：

```powershell
dotnet ef migrations add 给你的迁移起个名字 --project MyBlogApi/MyBlogApi.csproj --output-dir Data/Migrations
dotnet ef database update --project MyBlogApi/MyBlogApi.csproj
```

## 16. 表关系再看一遍

```text
Users 1 ──────< Articles >────── 1 Categories
  │                 │
  │                 │
  └────────< Comments >─────────┘
```

- `Articles.UserId` → `Users.Id`：一篇文章一个作者。
- `Articles.CategoryId` → `Categories.Id`：一篇文章一个分类，不能为空。
- `Comments.ArticleId` → `Articles.Id`：一条评论一篇文章。
- `Comments.UserId` → `Users.Id`：一条评论一个作者。
- 评论没有指向另一条评论的字段，所以不能回复。

外键都是 `ON DELETE NO ACTION`（代码里的 `DeleteBehavior.Restrict`）。想删分类，要先没有文章引用它。软删除的文章行还在，所以分类仍然删不掉。

## 17. 一次请求是怎么走的

以“发表评论”为例：

1. 浏览器请求 `POST /api/articles/1/comments`，Header 里有 `Authorization: Bearer token`。
2. JWT 中间件校验 token。不对就直接 401，进不了控制器。
3. `CommentController.Create` 从 token 取出用户 Id，把 body 绑定成 `CommentAddDto`。
4. 字段不合法时，`InvalidModelStateResponseFactory` 返回 400。
5. `CommentService` 检查用户是否有效、文章是否已发布，然后插入 `Comments`。
6. `BaseController.ToActionResult` 把结果包成 `ApiResult`，HTTP 200，`code` 200。
7. 中途没抓住的异常进 `GlobalExceptionFilter`，返回 500。

控制器、服务、数据库就是这三层。新手改需求时，校验和数据库操作放 Service，不要堆在 Controller 里。

## 18. 缓存什么时候生效

只有这两种读会用 Redis：

- `GET /api/articles` 已发布列表，缓存 5 分钟。
- `GET /api/articles/{id}` 里，不是作者本人查看已发布文章时，用详情缓存，缓存 10 分钟。

这些情况不走这层缓存：

- 作者看自己的文章
- `GET /api/articles/mine`
- 分类列表
- 评论列表

发布、修改、删除文章，或修改分类名称时，会换掉列表版本号，并删除对应详情键。旧缓存就不会再被读到。

Redis 没启动时，读缓存会失败并记日志，然后直接查 SQL Server。写接口仍然要求数据库可用。

## 19. 常见问题

**启动报“Jwt:Secret 至少需要 32 个字节”**

`appsettings.json` 里的密钥太短。换成至少 32 个字符的字符串。

**Swagger 打不开**

确认用的是 `http` 配置启动，地址是 `http://localhost:5184/swagger`。正式环境默认不打开 Swagger。

**建表失败，提示登录失败**

SQL Server 没起来，或 sa 密码和连接串不一致。

**删除分类一直失败**

该分类下还有文章行，包括 `IsDeleted = 1` 的文章。先处理这些文章记录。

**改了实体但数据库没变**

改类不会自动改表。要再执行 `dotnet ef migrations add` 和 `dotnet ef database update`。

**列表里没有 page**

这是当前项目的约定。列表一次返回全部，用 `result.total` 表示条数，用 `result.data` 表示数组。
